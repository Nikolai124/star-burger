# Сайт доставки еды Star Burger

Сайт сети ресторанов Star Burger, на котором можно заказать бургеры с доставкой на дом

## Как установить

Python3 должен быть уже установлен, версия 3.10 или выше. Для сборки фронтенда нужен [Node.js](https://nodejs.org/en/), проект проверен на версии 16.16.0.

Скачайте код и перейдите в папку проекта:
```
git clone https://github.com/Nikolai124/star-burger.git
cd star-burger
```

Создайте виртуальное окружение:
```
python -m venv venv
```

Активируйте его:

`.\venv\Scripts\activate`

Затем используйте `pip` (или `pip3`, есть конфликт с Python2) для установки зависимостей:
```
pip install -r requirements.txt
```

Установите пакеты Node.js:
```
npm ci
```

### Переменные окружения

Проект берёт настройки из файла `.env` в корне проекта, рядом с `manage.py`. Создайте файл ".env" и впишите свои значения.


| Переменная | Описание | Пример |
|---|---|---|
| `SECRET_KEY` | Обязательная. Секретный ключ Django для шифрования сессий и паролей | `django-insecure-0if40nf4nf93n4` |
| `DEBUG` | Режим отладки: `True` для разработки, `False` для продакшена. По умолчанию `True` | `True` |
| `ALLOWED_HOSTS` | Хосты, с которых разрешён доступ к сайту, через запятую. По умолчанию `127.0.0.1,localhost` | `127.0.0.1,localhost` |
| `YANDEX_GEOCODER_API_KEY` | Ключ API Яндекс.Геокодера. Без него сайт не узнает координаты адресов и не посчитает расстояния | `your-api-key` |

Сгенерировать `SECRET_KEY` можно командой:
```
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

### Как получить ключ Яндекс.Геокодера

1. Войдите в [Кабинет разработчика](https://developer.tech.yandex.ru/services/) через свой Яндекс ID.
2. Нажмите «Подключить API» и выберите «JavaScript API и HTTP Геокодер».
3. Заполните анкету, после этого ключ появится в кабинете.
4. Скопируйте ключ и вставьте его в `.env` после `YANDEX_GEOCODER_API_KEY=`.

### База данных

Создайте базу данных и примените миграции:
```
python manage.py migrate
```

Создайте суперпользователя, чтобы заходить в админку и панель менеджера:
```
python manage.py createsuperuser
```

## Как запустить

### Dev-версия

Нужно запустить одновременно бэкенд и фронтенд, каждый в своём терминале.

В первом терминале с активированным окружением запустите сервер:
```
python manage.py runserver
```

Во втором терминале запустите сборку фронтенда. Parcel будет следить за файлами в `bundles-src` и пересобирать их при изменениях:
```
.\node_modules\.bin\parcel watch bundles-src/index.js --dist-dir bundles --public-url="./"
```

Дождитесь сообщения `Built in ...` и откройте сайт [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Если страница пустая или сайт ведёт себя странно, сбросьте кэш браузера: <kbd>Ctrl-F5</kbd>.

- админка: [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)
- панель менеджера: [http://127.0.0.1:8000/manager/](http://127.0.0.1:8000/manager/)

Чтобы в меню появились блюда, а в панели менеджера рестораны и расстояния, добавьте в админке товары, рестораны с адресами и их меню.

### Prod-версия

Соберите фронтенд:
```
.\node_modules\.bin\parcel build bundles-src/index.js --dist-dir bundles --public-url="./"
```

В `.env` поставьте `DEBUG=False`, свой `SECRET_KEY` и адрес сайта в `ALLOWED_HOSTS`.

### Тесты

```
python manage.py test foodcartapp restaurateur
```
